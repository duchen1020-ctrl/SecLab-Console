边界与说明

这套控制台是怎么搭的，以及它刻意不做哪些事。

v12.0LOCAL ONLY
01

安全护栏

GUARD
  • 监听地址仅 127.0.0.1:8848，不对外网暴露 Web 界面。
  • 目标白名单默认只允许 loopback / 内网 IP / .local 等靶场域名，公网目标需显式二次确认。
  • 无害载荷XSS 只用 alert(1)；命令注入只用 echo 标记与只读侦察命令；SQL 只读查询，不做写操作。
  • 命令白名单默认禁止连接符与非只读命令，解除前会显示风险提示。
  • 速率限制所有模块带请求间隔，避免把靶场打挂。
02

技术架构

STACK
  • 后端Python 3 + Flask，多线程任务队列，日志增量推送。
  • 前端原生 HTML / CSS / JS，无构建步骤，离线可用。
  • SQL 引擎ORDER BY 列数探测 → UNION 回显定位 → 标记包裹提取 → GROUP_CONCAT 批量枚举；回显不可用时切换到 ASCII 二分盲注。
  • XSS 引擎8 向量矩阵 + 反射分类 + 上下文定位；存储型支持自动提交、回读校验与 POC 提交页。
  • 任务每个动作独立任务，可中止、可追溯、结论自动归档。
03

从脚本到平台

UPGRADE
01 交互方式

原来每个脚本都需要命令行 input() 交互，现在统一为 Web 表单 + 一键流水线。

02 数据提取

原脚本靠 "First name:" 正则猜结果，现改为 ~z~value~z~ 唯一标记精确回显。

03 枚举效率

库名 / 表名 / 字段名改用 GROUP_CONCAT 一次取回，请求数从 O(n) 降到 1。

04 可观测性

实时日志、进度、请求计数与中止能力，替代散落在终端里的 print。

05 结论沉淀

任务结束后自动归档，支持导出 Markdown 报告，便于写实验报告。

06 安全边界

新增目标护栏、命令白名单、速率限制，避免工具被误用到非授权目标。

07 盲注提取

UNION 不回显时，按 ASCII 二分逐字符提取，覆盖布尔盲注场景。

08 存储型 XSS

自动提交留言并回读校验，输出持久化强度与可执行载荷。

09 报告与代理

各模块一键导出 Markdown 报告；支持 HTTP 代理接入 Burp 观察流量。

10 全库导出

一次遍历数据库内所有表，按行导出并生成 JSON / CSV。

11 多参数与 DOM

XSS 支持逗号分隔多参数批量检测，并可静态分析 source → sink 数据流。

12 喷洒与正则

弱口令支持密码喷洒、正则判定、字典文件导入与 429 自动停止。

13 防御面审计

检查 CSP、X-Frame-Options、安全 Cookie 等响应头，给出 A–D 评分与整改建议。

14 盲命令探测

无回显时用 ping / sleep 的响应延迟确认命令执行，覆盖盲注场景。

15 历史详情

任务结果完整归档，点击记录即可回看证据并下载 JSON。

16 表单识别

自动解析页面表单的 method / action / 字段，POST 靶场一键套用。

17 盲打接收端

生成盲打载荷并收集回连命中，记录触发页面与 UA。

18 任务中心

独立任务队列页面，实时进度、日志回放与中止。

19 难度切换

顶栏 SEC 一键切换 LOW / MEDIUM / HIGH，自动改写四个模块的 Cookie。

20 High SQLi

自动识别 session-input.php，先写入会话 ID 再读取结果；UNION 标记扫列兜底。

21 High 爆破与命令

自动刷新轮换 token；命令注入用 || 与 whoami 回显确认。

22 深度向量库

18 条 SVG / MathML / autofocus / srcdoc / 伪协议向量，覆盖 high 的解析器差异。

23 失败自动降级

UNION 无法回显时自动切布尔盲注，再失败切时间盲注。

24 Cookie 会话

改用 CookieJar，服务端 Set-Cookie 可回传，支持 high 的 cookie-input 盲注。

25 盲注拖库

无回显时按 HEX 逐字节提取，库名 → 表名 → 字段 → 数据全链路可拖。

26 存储型深度

存储型 XSS 可套用 19 条深度向量，一次写入、回读、判定编码与否。

27 全模块回归

一键复测四个模块，附带代理端口连通性检查，切换难度或开 Burp 后先跑一次。

28 自动登录

填靶场账号密码，自动带 CSRF token 登录并抓取新的 PHPSESSID，一键写入四个模块。

29 难度矩阵

不改配置，直接用同一套目标跑 LOW / MEDIUM / HIGH，一屏对比三档的过滤差异。

30 总报告

把全部任务归档渲染成可离线打开、可直接打印的 HTML 报告。

31 Cookie 巡检

进页面查一次、之后每 5 分钟一次；失效时顶栏弹提示，可一键用上次账号重登。

32 矩阵导出

难度矩阵可导出 Markdown，含总览表格与每档细节，直接贴进实验报告。

33 批量扫描

粘一份 URL 清单，按顺序跑同一模块的最小验证，结果可载入到模块页继续深挖。

34 一键全流程

四个模块一次跑完并出汇总报告，SQLi 会一路做到库列表，弱口令可选附加。

35 配置档

保存四模块地址 / Cookie / 参数 / 难度，换靶场一键还原，可导出 JSON 备份。

36 授权留痕

勾选「授权公网目标」需二次确认，确认记录会写进导出的报告。
